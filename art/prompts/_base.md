# Base prompt (append to every prompt)

Pixel art game asset for a 2D side-view fantasy sandbox game. Chunky pixels, dark colored 1-pixel outlines, flat 2–3 tone shading lit from the top-left, saturated mystical-forest colors, no anti-aliasing, no gradients, no text, no shadows on the ground. Match the style and colors of the attached reference image exactly.

## Rules

- **Always attach `art/reference/style-reference.png`** to the prompt (once it exists).
- Never name an existing game in a prompt, and never upload screenshots of other games as references. Describe the style in words.
- Record the template and the filled-in specifics in the asset's `prompt` field in `art/manifest.json`.
- Save the result to `art/raw/<category>/<manifest id>.png`.
