# M5 art batch: the forest look

Generated in production order (plan 2.9.10). For each prompt:

1. Copy the whole block into Gemini (Nano Banana).
2. **Attach `art/reference/style-reference.png`.** Make that image first, from `art/prompts/style-reference.md`.
3. Save the best result as `art/raw/<raw path>`.

Then tell Claude Code to import the batch.

Parallax layers are fully coloured, with distance haze painted in: farther layers are lighter and bluer. The game only adds time-of-day light on top. The current white silhouettes are placeholders that the game tints.
